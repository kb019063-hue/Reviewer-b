Because EMUI 9.1 cannot receive further OTA updates, running these 1-line ADB commands once gives you the deepest possible system performance and permanently strips system bloat.

1-Click Copy

Permanent Bloat Stripper Script

Uninstall HiSearch, HiView, and telemetry completely without rooting. Paste this into your terminal or ADB Shell:

pm uninstall -k --user 0 com.huawei.search && pm uninstall -k --user 0 com.huawei.intelligent && pm uninstall -k --user 0 com.huawei.hiview && pm uninstall -k --user 0 com.huawei.bd && pm uninstall -k --user 0 com.huawei.vassistant && pm uninstall -k --user 0 com.facebook.appmanager

Undo any of it with pm install-existing <package> — this removes the app for the current user only, the factory copy stays on the system partition.
