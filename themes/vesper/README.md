# Vesper for EMUI 9.1

A warm, dark theme for the Huawei P20 Lite (ANE-LX1): dusk wallpapers, copper-accented line icons and Inter typography.

## Install

1. Copy `Vesper-Safe-EMUI91.hwt` to your phone. Keep the `.hwt` extension.
2. In Files, place it in the phone's `Huawei/Themes` folder (some EMUI versions use `HWThemes` instead). Create the folder if necessary.
3. Open **Themes** → **Me** → **Themes**, select **Vesper Safe**, and apply it. Restart Themes or the phone if it doesn't appear. Folder names and menus can vary by firmware.
4. Optionally try `Vesper-EMUI91.hwt`, which also requests dark system colours. If any text becomes hard to read, reapply Vesper Safe or a stock theme.

The safe version still includes launcher settings, icons and fonts; it omits the system colour overrides. Actual application of individual resources depends on the firmware. Not every app icon is covered, and some apps or system surfaces may remain unchanged.

`Vesper-preview.png` and `Vesper-lockscreen-preview.png` are **design mockups**, not device screenshots. The illustrated widget, notifications, clock, and layout are not supplied as functional widgets or a custom lock screen.

The archives passed local ZIP, image, font and XML checks, but have **not** been imported or applied on a physical ANE-LX1 running EMUI 9.1. Compatibility cannot be guaranteed.

## Rebuild

Install Python dependencies `Pillow` and `fonttools`, then run `python build_vesper.py` from this directory. The script generates both archives and mockups; its temporary files go into `.work/`.

Artwork is generated by the script. The included Inter font is distributed under the SIL Open Font License; see `source/fonts/OFL-Inter.txt` and the license inside each theme archive.
