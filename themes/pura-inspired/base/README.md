# Compatibility skeleton (base/)

These files are the *structural* parts of a known-working community EMUI 9.1
theme package (`emui91b_dark.hwt`, github.com/nadeemtaj12/dark_emui91_theme):

- `unlock/theme.xml`, `unlock/layout-hdpi/layout1.xml`, `unlock/drawable-hdpi/*.png`
  — the standard EMUI 9.x "amazing" slide-lock module. EMUI 9.1 does not use the
  EMUI 11 `style="slide"` lock XML; a real 9.1 package uses `style="amazing"`
  with `layout1` and these small stock lock glyphs.
- `framework-res/theme.xml`, `systemui/theme.xml` — module XML with Huawei's
  standard resource names so the theme engine parses the modules.
- `launcher/res/drawable-xxhdpi/icon_mask.png`, `simple_icon_mask.png` — the
  generic EMUI rounded-square icon masks used by the launcher module.

They are used only as a parsing skeleton; all visible artwork in the built
`.hwt` (wallpaper, icons, previews) is generated by `build.py`. Reusing another
theme's framework XML/lock glyphs is standard practice for local EMUI theme
packages, but do not redistribute this package as a store upload.
